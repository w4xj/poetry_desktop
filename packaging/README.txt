诗词壁纸 — Windows 64 位

（版本号见所在目录名或安装包文件名，例如 poetry_desktop-0.2.0-windows-x64。）

绿色版：解压后双击 poetry_desktop.exe 即可，不需要安装 Qt 或任何运行库。
安装版：按当前 Windows 用户安装到 %LOCALAPPDATA%\Programs\PoetryDesktop，不需要管理员权限；
安装后会创建开始菜单和桌面快捷方式，卸载入口在 Windows「设置 → 应用」里。
两种方式使用同一份程序，所需的 Qt 组件与编译器运行时都已随包携带。

一、首次使用
1. 双击 poetry_desktop.exe。程序会常驻系统托盘，关闭主窗口只是隐藏，不会退出。
2. 首次启动会出现两页向导：先看介绍，再选择底图 —— 内置 3 张示例图（推荐）、
   当前的桌面壁纸、自己的图片文件夹，或暂时跳过。示例图会复制到应用数据目录，
   不会改动你的原图。完成后程序会自动生成并应用第一张壁纸。
   之后也可以从「更多 → 首次使用引导」重新打开向导。
3. 「图片库」页可随时增删图片目录，也可以点「选择图片…」单独指定一张。
4. 「诗词库」页内置了示例诗词（含一首赠答双诗），可直接使用；点「导入诗词 JSON」
   可导入自己的库。导入文件格式要求：顶层是一个 JSON 对象，其中包含 poems 数组，
   每条至少有 content 字段。
5. 一首诗词可以是单首，也可以是由两首组成的酬答类体裁（一赠一酬、原唱奉和、一问一答）。
   在「添加诗词 / 编辑选中」的「体裁」下拉里选择，之后会出现「下首」分组。
   这类作品在壁纸上分上下两块展示，每块顶部标出「赠」「酬」一类关系标签；
   标签与块间距在「显示设置 → 版面」里可调。
   双诗的底板有两种形式（「显示设置 → 版面 → 双诗面板」）：合并为一个面板，
   或上下两首各自独立成一个面板、中间透出壁纸背景。
6. 在右侧或「显示设置」页调好字体、字号、颜色与位置后，左侧预览会实时更新。
   预览不会改动桌面，确认无误再点「应用当前预览」。

二、按钮语义（重要）
随机换一张壁纸 —— 随机选一张图片和一首启用的诗词，合成后直接设置桌面。
应用当前预览 —— 把当前预览原样设为桌面，不重新随机。
重新预览     —— 只刷新左侧预览，不改动桌面。
导出         —— 把当前成品保存为 PNG/JPG，或复制到剪贴板。
将选中图片设为壁纸 —— 直接把选中的原图设为桌面，不叠加任何诗词。
开启 / 暂停定时 —— 按设定间隔自动切换。程序重启后从启动时间重新计时，不补偿错过的切换。

三、历史、收藏与开机自启
「历史」页保留最近 20 次成功应用记录：
    重新应用 —— 用当前排版设置重新生成，不依赖缓存；
    收藏     —— 最多 50 条，随机切换时会偶尔回放收藏的搭配；
    排除底图 —— 只是不再随机使用这张图，原文件不会被删除，可随时恢复。
「定时与高级」页可勾选「登录 Windows 后自动启动」，无需管理员权限，
登录后程序静默驻留托盘。

四、数据位置
配置、缓存与日志都在：
    %LOCALAPPDATA%\PoetryDesktop\PoetryDesktop\
        config.json            全部设置与诗词库
        samples\               首启向导复制的示例图与当前桌面壁纸
        cache\wallpapers\      合成出的壁纸，保留最近 10 张
        logs\app.log           运行日志，超过 1 MB 自动轮转为 app.log.1
配置文件损坏时程序会自动备份为 config.json.corrupt-<时间戳> 并回落到默认值，不会丢桌面。

五、环境要求
Windows 10 或 11，64 位。
屏幕需要至少约 671 像素的逻辑工作区高度；1920×1080 在 150% 缩放下可用，
1366×768 在 125% 缩放下不可用（窗口放不下，属于已知的支持边界）。
壁纸输出尺寸始终等于屏幕物理分辨率，字体大小随分辨率自动缩放。

六、退出与卸载
主窗口右上角「更多」菜单里的「退出」，或系统托盘图标右键菜单的「退出」。
若提示「诗词壁纸已经在运行中」，说明确有实例常驻托盘；先退出它，
或确认没有残留进程后删除 %LOCALAPPDATA%\PoetryDesktop\PoetryDesktop\poetry_desktop.lock。
安装版可在 Windows「设置 → 应用 → 已安装的应用」里卸载，或运行安装目录下的
Uninstall.exe。卸载只删除程序文件，不会删除上一条里的配置、示例图和缓存。

七、离线运行
本程序不联网，不上传任何数据，不读取图片目录以外的个人文件。
