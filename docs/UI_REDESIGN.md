# 诗词壁纸 MVP UI 改版方案

- **文档状态**：第一轮 UI/UX 改版方案
- **目标**：解决当前 MVP 的三个用户反馈
  1. 修改字体后预览/壁纸没有立即体现；
  2. 用户找不到“直接切换桌面图片”的入口；
  3. 当前主窗口信息和操作分散，界面布局杂乱。
- **适用范围**：仅调整 UI 信息架构、交互和验收要求，不修改本轮业务代码。
- **参考文件**：`src/ui/main_window.cpp`、`src/ui/main_window.h`、`docs/PRODUCT_SPEC.md`

## 1. 当前问题审查

### 1.1 当前主窗口结构

现有 `setupUi()` 将以下内容全部纵向堆叠在同一窗口：

1. 顶部状态文本、资源数量、下次切换时间；
2. 最近一次成功预览；
3. 立即切换、暂停定时、打开缓存、清理缓存；
4. 图片库和诗词库横向分栏；
5. 显示设置与定时设置。

当前实现虽然功能覆盖较全，但存在明显的信息架构问题：

- 首屏同时出现“预览、图片目录、诗词表格、颜色、字体、定时”等多个层级，用户不知道从哪里开始；
- “立即切换”是全局按钮，但“使用某一张图片切换桌面”的入口不存在；
- 图片库实际管理的是目录，不是用户可以直接选中的图片，用户无法快速表达“我就要这张图”；
- 显示设置位于页面底部，且没有明确说明设置改变后是否会影响当前预览或桌面；
- `currentFontChanged`、字号变化等信号当前只连接到 `saveSettings()`，保存配置不等于重新渲染预览，因此字体变化不会立即反馈；
- 主状态、操作反馈和错误信息都写入顶部状态标签，缺少“当前桌面状态”“预览状态”“后台任务状态”的层级区分；
- “暂停定时”按钮在定时未启用时仍可能出现在快速操作区，文案和当前状态不够明确；
- 图片库没有“当前选中图片”“当前预览图片”和“当前桌面图片”的概念区分。

### 1.2 当前代码对 UX 的直接影响

现有行为中需要特别关注：

- `saveSettings()` 负责持久化配置，但没有触发重新生成当前预览；
- `updatePreview()` 只展示最近一次成功生成的壁纸文件；
- `requestManualSwitch()` 随机抽取诗词和图片，并直接执行生成与设置桌面；
- 图片库只有目录列表，没有图片级选择器；
- `m_config.runtime.lastImagePath` 只记录最近一次成功切换使用的图片，不等于用户当前选择的图片；
- `m_switchBusy` 只保护“切换任务”并发，尚未定义“修改设置后预览刷新”与切换任务之间的交互。

本改版不要求本轮直接修改上述代码，但程序员实现时必须增加明确的 UI 草稿状态和预览刷新入口，不能继续把“保存设置”当成“刷新预览”。

## 2. 改版目标与交互原则

### 2.1 改版目标

用户打开主窗口后，应在 5 秒内理解并完成以下操作：

1. 看懂当前桌面是否已应用成功；
2. 点击一个明确的主按钮随机换一张壁纸；
3. 选择某一张图片并直接将其设置为桌面；
4. 修改字体后立即在预览中看到变化；
5. 知道预览变化是否已经应用到桌面；
6. 找到定时开关和下一次切换时间；
7. 资源管理和高级设置不会干扰主要切换流程。

### 2.2 交互原则

- **预览和桌面是两个状态**：预览改变不自动覆盖桌面，必须有明确的“应用到桌面”反馈。
- **主任务优先**：随机切换、应用当前预览、选择图片位于首屏；导入、删除、缓存等低频操作下沉到资源页或更多菜单。
- **所见即所得**：字体、字号、位置、颜色、底板、阴影变化后，预览在短延迟内更新。
- **操作命名描述结果**：避免只使用“切换”“保存”等含义不完整的词，按钮文案要说明是否随机、是否设置桌面。
- **单一主按钮**：同一界面区域最多一个主色按钮，避免多个按钮竞争。
- **状态分层**：当前桌面状态、预览未应用状态、后台扫描/生成状态分别展示。
- **低频功能不抢空间**：缓存、日志、目录移除等不放在主操作区。

## 3. 主界面信息架构

### 3.1 总体布局

采用“顶部状态栏 + 左侧预览/主操作 + 右侧快捷控制 + 底部资源标签页”的结构。

```text
┌────────────────────────────────────────────────────────────┐
│  诗词壁纸                         当前桌面状态   定时开关  │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  ┌──────────────────────────────┐  ┌────────────────────┐  │
│  │                              │  │ 快速操作           │  │
│  │        壁纸预览画布           │  │ [随机换一张]       │  │
│  │                              │  │ [应用当前预览]     │  │
│  │  预览状态/未应用提示          │  │                    │  │
│  └──────────────────────────────┘  │ 当前诗词/图片摘要  │  │
│                                    │ 定时状态           │  │
│                                    └────────────────────┘  │
│                                                            │
├────────────────────────────────────────────────────────────┤
│ [图片库] [诗词库] [显示设置] [定时与高级]                  │
│                                                            │
│                       当前标签页内容                       │
└────────────────────────────────────────────────────────────┘
```

### 3.2 顶部状态栏

顶部只保留全局状态，不放资源管理按钮。

从左到右建议为：

1. 应用名称：`诗词壁纸`；
2. 当前桌面状态徽标；
3. 资源数量摘要：`图片 128 · 诗词 36`；
4. 定时状态：`定时已关闭`或`每 30 分钟 · 下次 14:30`；
5. 右侧更多菜单：打开缓存目录、打开日志目录、关于、退出。

顶部状态徽标只允许使用以下几种主状态：

- `已应用`：当前预览内容已经成功设置为桌面；
- `预览未应用`：预览已经变化，但桌面仍是上一次内容；
- `正在生成`：正在生成或设置桌面；
- `资源不足`：图片或诗词库为空/无有效条目；
- `切换失败`：最近一次设置桌面失败。

### 3.3 左侧预览区

预览区是主界面的视觉中心，默认占窗口宽度约 65%～70%。

预览区包含：

- 最近一次有效合成图或当前草稿预览；
- 图片适配后的真实比例展示；
- 诗词文字实际效果；
- 右上角小标签：`预览`、`已应用`或`未应用`；
- 底部轻量提示：`修改字体后会实时更新预览，点击“应用当前预览”设置到桌面`。

没有可用预览时，不显示空白黑框，而显示空状态：

```text
还没有可用预览
请先添加图片目录并导入诗词库
[去图片库]  [去诗词库]
```

### 3.4 右侧快速控制区

右侧固定展示最常用的操作，避免用户在页面底部寻找按钮。

#### 主要按钮

| 优先级 | 文案 | 行为 |
|---|---|---|
| 主按钮 | **随机换一张** | 随机抽取一条启用诗词和一张启用图片，生成并直接设置为桌面 |
| 次按钮 | **应用当前预览** | 不重新随机，使用当前预览内容直接设置为桌面 |
| 辅助按钮 | **重新预览** | 使用当前选中的诗词/图片和当前显示设置重新生成预览，不设置桌面 |
| 状态按钮 | **暂停定时** / **恢复定时** | 根据当前定时状态切换；定时关闭时显示“开启定时”或将该操作放入定时设置页 |

“随机换一张”必须明确说明它会直接设置桌面。禁止继续使用含义不完整的“立即切换”作为唯一主按钮文案。

推荐按钮排列：

```text
[随机换一张]       ← 主按钮
[应用当前预览]     ← 有预览时可用
[重新预览]         ← 只更新预览
```

按钮状态：

- 没有有效图片或诗词：`随机换一张`禁用，并显示缺少资源的原因；
- 没有当前预览：`应用当前预览`禁用；
- 正在生成或设置桌面：三个按钮进入禁用或加载状态；
- 预览与桌面一致：`应用当前预览`可保持禁用，或显示为次要状态；
- 预览有未应用修改：顶部显示`预览未应用`，`应用当前预览`高亮可用。

### 3.5 右侧摘要区

快速控制区下方显示当前内容摘要：

```text
当前预览
诗词：静夜思
作者：李白
图片：mountain.jpg
来源：图片库 / 风景目录
```

摘要仅用于确认当前操作对象，不承担编辑功能。图片路径过长时显示文件名，完整路径放在 tooltip 或详情弹窗中。

## 4. 底部资源与设置标签页

采用 `QTabWidget`，默认打开“图片库”或上次使用的标签页。标签页顺序如下：

1. 图片库；
2. 诗词库；
3. 显示设置；
4. 定时与高级。

### 4.1 图片库标签页

图片库必须同时表达三件事：资源来源、当前选中图片、切换入口。

#### 页面结构

```text
图片库
[选择图片…] [添加图片目录] [重新扫描]

图片来源
☑ C:\Pictures\poetry
☑ D:\Wallpapers\nature

当前选中图片
┌────────────────────────────────────────┐
│ 缩略图       mountain.jpg              │
│              1920×1080 · 2.4 MB        │
└────────────────────────────────────────┘
[使用选中图片预览] [切换当前图片]

扫描状态：有效图片 128 张，跳过 3 张
```

#### 必须提供的入口

##### `选择图片…`

打开图片选择器，展示当前扫描到的有效图片；至少支持：

- 缩略图或列表显示；
- 文件名显示；
- 单选；
- 确定、取消；
- 重新扫描；
- 当前图片高亮。

MVP 可先使用列表模式，不强制实现完整瀑布流缩略图。但不能只展示目录，必须让用户选择到具体图片。

如果用户通过文件选择器选择了库外图片，有两种产品策略：

- 推荐：将该图片作为“临时选中图片”，立即可预览和设置，但不自动复制、不删除、不修改源文件；
- 可选：提示用户将其所在目录加入图片库。

##### `使用选中图片预览`

行为：

1. 将选中图片与当前诗词、当前显示设置合成预览；
2. 不随机更换图片；
3. 不立即修改桌面；
4. 顶部状态变为`预览未应用`；
5. 右侧摘要更新为选中的图片。

##### `切换当前图片`

行为：

1. 使用当前选中图片；
2. 使用当前预览中的诗词，若没有当前预览则随机选择一条启用诗词；
3. 按当前显示设置生成壁纸；
4. 直接设置 Windows 桌面；
5. 成功后更新预览、当前桌面状态和最近使用记录。

按钮文案必须包含“当前图片”，避免用户误以为会随机换图。

推荐在按钮旁添加说明：

> 使用选中的图片，不随机图片；诗词沿用当前预览。

#### 图片库状态

- 未选择图片：显示`请选择一张图片`，两个图片操作按钮禁用；
- 选中图片不可读：显示错误原因，不能进入预览；
- 选中图片已被删除：自动清除选择并提示重新扫描；
- 图片库为空：显示引导按钮`选择图片…`和`添加图片目录`；
- 扫描中：保留已有列表，显示`正在扫描，新文件将在完成后更新`。

### 4.2 诗词库标签页

诗词库页面只负责内容管理，不与主切换按钮竞争。

页面结构：

```text
诗词库                         共 36 条 · 启用 32 条
[导入诗词 JSON] [刷新] [删除选中]

☑ 标题       作者       正文摘要
☑ 静夜思     李白       床前明月光 / 疑是地上霜
☐ ...

当前选中诗词：[使用选中诗词预览]
```

本轮不要求新增复杂编辑器，但建议增加：

- `使用选中诗词预览`：不切换桌面，只替换当前预览中的诗词；
- 启用/停用状态明显可见；
- 删除前确认；
- 导入结果放在页面内提示，不长期占用顶部主状态。

### 4.3 显示设置标签页

显示设置必须围绕“看着预览调效果”设计，而不是独立的配置表格。

页面结构：

```text
显示设置

字体
字体族        [微软雅黑                     v]
字号          [28 pt     -  +]
文字颜色      [颜色按钮]

文字布局
文字位置      [右下                       v]
图片适配      [铺满                       v]
☑ 文字底板    底板颜色 [颜色按钮]
☑ 文字阴影

提示：修改后会立即更新左侧预览，不会自动修改桌面。
[恢复默认显示设置]
```

#### 字体即时预览交互

字体族、字号、文字颜色、文字位置、图片适配、底板和阴影等设置发生变化时：

1. 立即更新内存中的“草稿显示设置”；
2. 在 150～300 ms 防抖后刷新左侧预览；
3. 不等待用户点击“保存”；
4. 不自动设置 Windows 桌面；
5. 预览成功后将顶部状态标记为`预览未应用`；
6. `应用当前预览`按钮变为可用并保持高亮；
7. 配置可以立即持久化，但“配置保存成功”和“桌面已更新”必须分开显示；
8. 生成失败时保留上一次可用预览，显示内联错误，不清空预览。

推荐交互文案：

- 设置页提示：`修改后立即更新预览，不会自动更换桌面`；
- 预览状态：`预览已更新，尚未应用到桌面`；
- 应用成功：`已应用到桌面`；
- 应用失败：`预览已更新，但设置桌面失败`。

#### 修改字体时的边界行为

- 字体不存在或不可渲染：使用回退字体，并提示`字体不可用，已使用系统回退字体`；
- 长诗词超过预览区域：自动换行或返回可理解的错误，不能让预览消失；
- 连续快速修改字体：只处理最后一次有效设置，避免并发刷新覆盖；
- 预览刷新期间修改其他设置：合并为下一次刷新，不允许旧任务覆盖新设置；
- 正在执行“随机换一张”时修改字体：设置可以更新草稿，但当前切换任务使用开始时的快照；任务完成后按最新设置重新生成预览或给出明确状态。

### 4.4 定时与高级标签页

定时从主界面移除复杂控件，但顶部保留状态和快捷开关。

页面结构：

```text
定时切换
☑ 开启定时切换
切换间隔       [30] 分钟
下次切换       2026-08-04 14:30

说明：程序重启后按启动时间重新计时，不补偿错过的切换。

高级
[打开缓存目录]
[清理缓存]
[打开日志目录]
[恢复默认设置]
```

顶部快捷状态：

- 定时关闭：`定时已关闭`；
- 定时运行：`每 30 分钟 · 下次 14:30`；
- 定时暂停：`定时已暂停`。

## 5. 状态层级与反馈规范

### 5.1 一级状态：桌面结果状态

显示在顶部和预览右上角，回答“桌面现在是什么状态”。

| 状态 | 文案 | 颜色建议 | 说明 |
|---|---|---|---|
| 已应用 | `已应用到桌面` | 绿色 | 当前预览与桌面一致 |
| 未应用 | `预览未应用` | 橙色 | 预览比桌面更新 |
| 进行中 | `正在生成并设置桌面…` | 蓝色 | 任务正在执行 |
| 资源不足 | `缺少图片或诗词` | 橙色 | 无法生成 |
| 失败 | `设置桌面失败` | 红色 | 最近一次桌面操作失败 |

### 5.2 二级状态：当前操作反馈

显示在对应区域或按钮旁，回答“刚才这一步发生了什么”。

示例：

- 图片库：`正在扫描…`、`扫描完成：有效 128 张，跳过 3 张`；
- 诗词库：`导入完成：有效 36 条，跳过 2 条`；
- 预览：`预览已更新`；
- 设置桌面：`正在设置桌面…`、`桌面已更新`。

### 5.3 三级状态：可操作错误

错误信息必须放在产生错误的控件附近，并给出下一步动作。

不推荐：

> 操作失败。

推荐：

> 当前图片已不存在，请重新扫描或选择其他图片。
> [重新扫描]

### 5.4 日志

日志不在主界面长期展开。错误提示只显示用户需要处理的摘要，详细错误写入日志，并提供：

- `查看详情`；
- `打开日志目录`。

## 6. 关键用户流程改版

### 6.1 随机换一张

1. 用户点击右侧主按钮`随机换一张`；
2. 按当前有效资源随机选择诗词和图片；
3. 生成预览；
4. 直接设置桌面；
5. 成功：顶部显示`已应用到桌面`，更新预览；
6. 失败：保留原桌面和原预览，显示失败原因。

### 6.2 修改字体并应用

1. 用户打开`显示设置`；
2. 修改字体或字号；
3. 150～300 ms 内左侧预览更新；
4. 顶部显示`预览未应用`；
5. 用户点击`应用当前预览`；
6. 桌面更新成功后显示`已应用到桌面`。

### 6.3 选择某一张图片并切换桌面

1. 用户打开`图片库`；
2. 点击`选择图片…`；
3. 选择具体图片；
4. 点击`使用选中图片预览`，确认效果；
5. 点击`切换当前图片`，直接应用到桌面；
6. 或返回主操作区点击`应用当前预览`。

### 6.4 只预览，不修改桌面

1. 用户选择图片或诗词；
2. 点击`使用选中图片预览`或`使用选中诗词预览`；
3. 预览更新；
4. 桌面保持不变；
5. 用户需要明确点击`应用当前预览`才会修改桌面。

## 7. 按钮和文案规范

### 7.1 推荐文案

| 原文案/现状 | 改版文案 | 原因 |
|---|---|---|
| 立即切换 | **随机换一张** | 明确随机且立即设置桌面 |
| 暂停定时 | **暂停定时** / **恢复定时** | 根据状态动态变化 |
| 添加目录 | **添加图片目录** | 明确目录用途 |
| 重新扫描 | **重新扫描图片** | 明确扫描对象 |
| 导入 JSON | **导入诗词 JSON** | 明确文件内容 |
| 打开缓存目录 | 放入更多菜单或高级设置 | 降低主界面干扰 |
| 清理缓存 | 放入更多菜单或高级设置 | 低频操作，不占主按钮区 |
| 无现有入口 | **选择图片…** | 具体选择单张图片 |
| 无现有入口 | **使用选中图片预览** | 只更新预览，不修改桌面 |
| 无现有入口 | **切换当前图片** | 使用选中图片直接设置桌面 |
| 无现有入口 | **应用当前预览** | 明确将当前预览设置到桌面 |

### 7.2 危险操作

- `删除条目`需要确认；
- `清理缓存`需要说明不会删除源图片并保留当前壁纸；
- 不使用红色主按钮表示普通切换；
- `退出`仅放在托盘菜单或更多菜单中。

## 8. 实现边界和数据状态建议

本轮是 UI/UX 方案，不修改业务代码，但为避免再次出现“保存成功、预览不变”的问题，程序员实现时需要明确以下状态：

### 8.1 UI 状态模型

至少区分：

- `currentPreviewImage`：当前预览的合成图；
- `currentDesktopImage`：最近一次成功设置的合成图；
- `selectedSourceImage`：图片库当前选中的源图片；
- `selectedPoem`：诗词库当前选中的诗词；
- `draftRenderSettings`：用户正在编辑的显示设置；
- `previewDirty`：预览是否比桌面更新；
- `previewBusy`：预览刷新任务是否执行中；
- `switchBusy`：设置桌面任务是否执行中。

不能继续仅使用 `lastSuccessfulWallpaper` 推断当前预览状态。

### 8.2 预览刷新入口

所有会影响画面的控件都必须连接到统一的预览刷新入口：

- 字体族；
- 字号；
- 文字颜色；
- 文字位置；
- 图片适配；
- 底板开关和颜色；
- 阴影开关；
- 选中图片；
- 选中诗词。

`saveSettings()` 只负责持久化，不应作为唯一的视觉更新入口。

### 8.3 预览与设置桌面分离

推荐接口语义：

- `refreshPreview()`：仅生成或刷新预览，不调用 Windows 壁纸 API；
- `applyCurrentPreview()`：将当前有效预览设置到桌面；
- `randomizeAndApply()`：随机资源、生成并设置桌面；
- `applySelectedImage()`：使用选中图片生成并设置桌面。

如果现有 `WallpaperService::run()` 同时承担“生成 + 设置桌面”，UI 仍需在交互层区分调用意图，不能让“字体调整”触发桌面修改。

## 9. UI 改版验收标准

以下标准作为本轮 UI/UX 改版的验收基线。编号独立于 `PRODUCT_SPEC.md` 的 AC 编号。

### 9.1 主界面信息架构

- **UI-001**：程序启动后，首屏能同时看到预览、`随机换一张`和`应用当前预览`，不需要滚动或切换标签页。
- **UI-002**：图片库、诗词库、显示设置、定时与高级内容通过明确标签页分组，不再全部纵向堆叠在首屏。
- **UI-003**：首屏主操作不超过三个：`随机换一张`、`应用当前预览`、`重新预览`。
- **UI-004**：用户无需阅读帮助即可理解：`随机换一张`会直接设置桌面，`应用当前预览`不会重新随机。
- **UI-005**：窗口宽度 1000～1280 像素时，主按钮、预览区和状态摘要不发生重叠或截断。
- **UI-006**：资源数量、当前桌面状态和定时状态在顶部可见，但不与错误提示混在同一个长文本中。

### 9.2 字体即时预览

- **UI-010**：修改字体族后，300 ms 内预览开始刷新；预览完成后显示新字体效果。
- **UI-011**：修改字号、颜色、文字位置、图片适配、底板或阴影后，预览同步更新。
- **UI-012**：显示设置变化不会自动调用 Windows 壁纸设置，桌面保持不变。
- **UI-013**：预览更新后顶部明确显示`预览未应用`，且`应用当前预览`变为可用。
- **UI-014**：点击`应用当前预览`后，桌面使用当前预览内容，不能重新随机图片或诗词。
- **UI-015**：应用成功后显示`已应用到桌面`，预览和桌面状态一致。
- **UI-016**：预览刷新失败时保留上一次有效预览，并在设置页或预览区显示可操作错误，不显示空白画布。
- **UI-017**：连续快速修改字体和字号时，最终预览必须对应最后一次设置，旧任务不能覆盖新设置。
- **UI-018**：程序重启后，字体设置和最近一次成功预览状态正确恢复。

### 9.3 图片选择和直接切换

- **UI-020**：图片库页面存在清晰可见的`选择图片…`入口。
- **UI-021**：用户可以从已扫描资源中选择一张具体图片，而不是只能选择目录。
- **UI-022**：选择图片后，页面显示文件名、缩略图或预览、尺寸和有效状态。
- **UI-023**：点击`使用选中图片预览`只更新预览，不改变桌面。
- **UI-024**：点击`切换当前图片`使用选中图片设置桌面，不重新随机图片。
- **UI-025**：没有选中图片时，`使用选中图片预览`和`切换当前图片`不可用，并显示`请选择一张图片`。
- **UI-026**：当前图片被删除或不可读取时，界面清除无效选择并提供`重新扫描`或`选择图片…`操作。
- **UI-027**：从图片库完成切换后，主预览、当前桌面状态、最近图片摘要保持一致。
- **UI-028**：用户点击`随机换一张`时，界面明确显示图片和诗词都可能变化。

### 9.4 状态层级

- **UI-030**：桌面结果状态只使用`已应用到桌面`、`预览未应用`、`正在生成并设置桌面`、`缺少图片或诗词`、`设置桌面失败`等有限状态。
- **UI-031**：扫描、导入、预览、设置桌面等操作的反馈显示在对应区域，不使用顶部一个标签承载所有信息。
- **UI-032**：错误提示包含原因和下一步操作，例如`重新扫描`、`选择图片…`或`导入诗词 JSON`。
- **UI-033**：成功设置桌面后，不再显示旧的`正在生成`或旧错误信息。
- **UI-034**：定时关闭、运行和暂停三种状态在顶部和定时页文案一致。

### 9.5 兼容现有 MVP 验收

- **UI-040**：改版不破坏 `PRODUCT_SPEC.md` 中 AC-030～AC-040 的随机切换、失败保护和运行状态持久化。
- **UI-041**：改版不破坏 AC-050～AC-057 的图片适配和文字渲染设置。
- **UI-042**：改版不破坏 AC-060～AC-065 的定时切换与并发保护。
- **UI-043**：用户源图片不因选择、预览或设置桌面而被移动、覆盖或删除。
- **UI-044**：字体预览刷新和桌面设置任务并发时，最终桌面结果可解释，不能出现旧预览覆盖新预览。
- **UI-045**：设置失败时保留当前桌面和上一次成功预览，并显示失败原因。

## 10. 产品验收流程

### 10.1 快速验收路径

1. 启动软件；
2. 确认首屏能看到预览和两个核心按钮；
3. 打开显示设置，修改字体；
4. 确认预览即时变化，桌面暂不变化；
5. 点击`应用当前预览`，确认桌面变化；
6. 打开图片库，点击`选择图片…`；
7. 选择另一张图片并点击`使用选中图片预览`；
8. 确认预览变化且桌面暂不变化；
9. 点击`切换当前图片`；
10. 确认桌面使用了选中图片；
11. 点击`随机换一张`，确认图片和诗词都可变化；
12. 检查顶部状态、定时状态和资源数量是否清晰。

### 10.2 不通过条件

出现以下任一情况，本轮 UI 改版不通过：

- 修改字体后预览没有变化，或必须重启/重新随机后才变化；
- 用户无法在首屏找到“应用当前预览”或“随机换一张”；
- 用户无法选择单张图片；
- `切换当前图片`实际又随机了另一张图片；
- 预览更新意外修改了桌面；
- 应用当前预览时重新随机了诗词或图片；
- 页面主要操作被资源表格或设置表单挤到需要滚动查找；
- 错误只显示为笼统的“操作失败”；
- 改版破坏原有随机切换、定时切换或失败保护行为。

## 11. 给程序员和测试 agent 的实现关注点

### 11.1 程序员 agent

1. 将预览刷新从 `saveSettings()` 中解耦出来；
2. 增加草稿显示设置和当前预览状态；
3. 增加防抖刷新，避免每次键盘输入都启动多个任务；
4. 区分“仅预览”和“设置桌面”两个调用链；
5. 增加图片级选择模型或图片选择对话框；
6. 增加 `applyCurrentPreview()` 语义明确的入口；
7. 明确 `lastSuccessfulWallpaper`、当前预览、选中图片三者的边界；
8. 预览刷新失败不能清空上一次有效预览；
9. 任务并发时保证旧预览不能覆盖新设置；
10. 将按钮 enabled/disabled 状态与资源、预览、任务状态绑定，而不是只绑定窗口生命周期。

### 11.2 测试 agent

至少新增以下测试：

- 修改字体后预览图片发生变化；
- 修改字体不会调用壁纸设置器；
- 应用当前预览调用壁纸设置器时使用当前预览路径；
- 选择图片后预览使用该图片；
- 切换当前图片不会重新随机图片；
- 未选择图片时相关按钮禁用；
- 快速连续修改字体最终只保留最后一次设置；
- 预览失败保留上一张有效预览；
- 随机换一张仍然同时支持随机诗词和随机图片；
- UI 标签页切换不会丢失已选图片和显示设置；
- 主界面在 1000、1120、1280 像素宽度下无明显重叠；
- Windows 实机验证“预览未应用”和“已应用到桌面”两个状态差异。

## 12. 改版完成判定

本轮 UI 改版建议分为两个阶段：

### 阶段一：交互闭环

必须完成：

- 新主界面信息架构；
- `随机换一张`；
- `应用当前预览`；
- `选择图片…`；
- `使用选中图片预览`；
- `切换当前图片`；
- 字体即时预览；
- `预览未应用`/`已应用到桌面`状态。

### 阶段二：视觉整理

随后完成：

- 标签页样式统一；
- 间距、字号、按钮层级优化；
- 空状态、错误状态和加载状态；
- 预览区自适应；
- 高 DPI 下的控件可读性；
- 托盘和主窗口文案统一。

只有阶段一全部满足 UI-001～UI-045 中的阻断项后，产品才可重新进行 UI 改版验收。
